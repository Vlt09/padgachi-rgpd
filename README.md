# Page RGPD — ZeroPerte

Site statique minimal pour héberger la politique de confidentialité de l'application via GitHub Pages.

## Fichiers

- `index.html` — la page (squelette avec sections à remplir, aucun contenu RGPD rédigé)
- `style.css` — mise en forme basique

## Mise en ligne avec GitHub Pages

1. Crée un repo (public) dédié, ex. `zeroperte-rgpd`, ou un dossier `/docs` dans le repo principal.
2. Place `index.html` et `style.css` à la racine du repo (ou du dossier `docs/`).
3. Sur GitHub : **Settings → Pages → Build and deployment → Source : Deploy from a branch**, puis choisis la branche (`main`) et le dossier (`/root` ou `/docs`).
4. L'URL publique sera du type `https://<ton-user>.github.io/<nom-du-repo>/` — c'est cette URL que tu mets dans le Play Store / la fiche de l'app.
